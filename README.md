# همزبان (Hamzaban)

مترجم دسکتاپ برای ویندوز، مک و لینوکس، در حال‌وهوای QTranslate و با ظاهر شیشه‌ای (Liquid Glass).
هر جای سیستم متنی را انتخاب کنید، میانبر را بزنید و ترجمه کنار نشانگر ماوس ظاهر می‌شود.

## دانلود

**[⬇ دانلود آخرین نسخه](https://github.com/shixshinobi/hamzaban/releases/latest)**

در صفحه‌ی دانلود، از بخش **Assets** فایل سیستم‌عامل خود را بردارید:

| سیستم‌عامل | فایل |
| --- | --- |
| ویندوز ۱۰ و ۱۱ (نصب) | `Hamzaban-Setup-…-x64.exe` |
| ویندوز روی پردازنده‌ی ARM (مثل Surface Pro X) | `Hamzaban-Setup-…-arm64.exe` |
| ویندوز (بدون نصب) | `Hamzaban-Portable-….exe` |
| مک با تراشه‌ی Apple (M1 به بعد) | `Hamzaban-…-mac-arm64.dmg` |
| مک اینتل | `Hamzaban-…-mac-x64.dmg` |
| لینوکس (همه‌ی توزیع‌ها) | `Hamzaban-…-linux-x86_64.AppImage` |
| اوبونتو و دبیان | `Hamzaban-…-linux-amd64.deb` |

همزبان هنوز امضای دیجیتال ندارد، برای همین بار اول سیستم‌عامل هشدار می‌دهد:

- **ویندوز**: در پیام «Windows protected your PC» روی **More info** و بعد **Run anyway** بزنید.
- **مک**: همزبان را از فایل dmg به Applications بکشید. بار اول روی برنامه راست‌کلیک کنید و **Open** را بزنید. اگر باز نشد، از System Settings ← Privacy & Security گزینه‌ی **Open Anyway** را بزنید.
- **لینوکس**: AppImage را با `chmod +x Hamzaban-*.AppImage` اجرایی کنید، یا deb را با `sudo apt install ./Hamzaban-*.deb` نصب کنید.

## امکانات

- **چند موتور ترجمه با یک کلیک**: گوگل ترنسلیت (رایگان و بدون کلید)، ChatGPT، Claude و Gemini با حساب کاربری خودتان، Codex CLI، Claude Code، Gemini CLI، Ollama (محلی) و هر تعداد کلید API که برای هر کدام مدل جداگانه تعیین می‌کنید (OpenAI، Anthropic، Gemini، OpenRouter، DeepSeek، Groq، Mistral، xAI یا هر سرویس سازگار با OpenAI).
- **رابط مولد (Generative UI)**: مدل زبانی جواب را به شکل بلوک‌های ساختاریافته می‌فرستد (کارت واژه‌نامه، معادل‌های دیگر، یادداشت مترجم، جدول، کد و…) و برنامه همان‌طور که جواب می‌رسد کامپوننت می‌سازد. اندازه‌ی پنجره و چیدمان هم بر اساس محتوا تغییر می‌کند: یک واژه کارت کوچک می‌گیرد و متن بلند نمای مطالعه‌ی پهن.
- **ترجمه‌ی تصویر**: ناحیه‌ای از صفحه را انتخاب کنید یا تصویر را بچسبانید. مدل‌های بینایی خودشان تصویر را می‌خوانند و برای گوگل، متن با OCR محلی (Tesseract) خوانده می‌شود.
- **ترجمه‌ی PDF**: صفحه‌به‌صفحه، با نمای کنار هم و خروجی Markdown، HTML یا متن ساده. صفحه‌های اسکن‌شده با OCR خوانده می‌شوند.
- **سبک‌ها و اسکیل‌ها**: برای حفظ لحن، دستورالعمل و واژه‌نامه‌ی اجباری بنویسید یا یک فایل `SKILL.md` وارد کنید.
- **جایگزینی در متن**: متن انتخاب‌شده را ترجمه می‌کند و همان‌جا جایگزین می‌کند.
- رابط فارسی راست‌به‌چپ با قابلیت تغییر به انگلیسی، پوسته‌ی روشن و تیره همگام با سیستم، و تاریخچه.

## میانبرهای پیش‌فرض

| کار | ویندوز و لینوکس | مک |
| --- | --- | --- |
| ترجمه‌ی متن انتخاب‌شده | `Ctrl+Alt+Q` | `⌘⌥Q` |
| ترجمه و جایگزینی متن انتخاب‌شده | `Ctrl+Alt+R` | `⌘⌥R` |
| انتخاب ناحیه از صفحه و ترجمه | `Ctrl+Alt+S` | `⌘⌥S` |
| ترجمه‌ی کلیپ‌بورد (متن یا تصویر) | `Ctrl+Alt+X` | `⌘⌥X` |
| باز کردن همزبان | `Ctrl+Alt+H` | `⌘⌥H` |

همه را از «تنظیمات ← میانبرها» عوض کنید. عمداً از `Alt+Shift` استفاده نشده، چون در ویندوز زبان صفحه‌کلید را عوض می‌کند.
در پنجره‌ی اصلی `Ctrl+Enter` ترجمه می‌کند و در پنجره‌ی شناور `Esc` آن را می‌بندد.

## اجرا

نیازمندی: Node.js نسخه‌ی ۲۰ یا بالاتر و pnpm.

```bash
pnpm install
pnpm dev          # اجرای حالت توسعه
pnpm build        # ساخت
pnpm dist:win     # نصب‌کننده‌ی ویندوز (NSIS و نسخه‌ی پرتابل)
pnpm dist:mac     # فایل DMG (باید روی مک ساخته شود)
pnpm dist:linux   # AppImage و deb
```

اگر دانلود Electron کند بود:

```bash
ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/" pnpm install
```

## راه‌اندازی موتورها

همه از «تنظیمات ← موتورها».

- **ChatGPT / Claude / Gemini (حساب کاربری)**: دکمه‌ی «ورود» پنجره‌ی خود سایت را داخل برنامه باز می‌کند. یک‌بار وارد شوید؛ از آن به بعد ترجمه‌ها در پس‌زمینه، در یک گفتگوی تازه، فرستاده و جواب خوانده می‌شود. نشست جدا از مرورگرتان نگه داشته می‌شود. ChatGPT حتی بدون ورود هم جواب می‌دهد (با محدودیت).
  - ورود با گوگل گاهی داخل Electron مسدود می‌شود. در این صورت با ایمیل وارد شوید، یا برای Gemini از Gemini CLI استفاده کنید.
  - اگر سایت ظاهرش را عوض کند، ممکن است این روش موقتاً کار نکند. انتخابگرها در `electron/engines/web.ts` داخل `SITES` هستند.
- **Codex CLI / Claude Code / Gemini CLI**: روش رسمی‌تر و پایدارتر برای استفاده از اشتراک خودتان. دکمه‌ی «نصب» دستور نصب را در ترمینال اجرا می‌کند و «ورود» دستور ورود را:
  - `npm i -g @openai/codex` و سپس `codex login` (گزینه‌ی Sign in with ChatGPT)
  - `npm i -g @anthropic-ai/claude-code` و سپس `claude`
  - `npm i -g @google/gemini-cli` و سپس `gemini`
- **Ollama**: اگر Ollama روی سیستم اجرا باشد، با «دریافت فهرست مدل‌ها» مدل را انتخاب کنید.
- **کلید API**: «افزودن کلید API» را بزنید، سرویس‌دهنده را انتخاب کنید و کلید و مدل را وارد کنید. هر کلید یک موتور جداست با مدل خودش. کلیدها با رمزنگاری سیستم‌عامل (safeStorage) ذخیره می‌شوند.

## دسترسی‌های لازم

- **مک**: برای خواندن متن انتخاب‌شده، دسترسی Accessibility؛ برای ترجمه از روی صفحه، Screen Recording.
- **لینوکس**: متن انتخاب‌شده مستقیم از PRIMARY selection خوانده می‌شود. برای «جایگزینی در متن» بسته‌ی `xdotool` لازم است. روی Wayland ممکن است میانبرهای سراسری محدود باشند.
- **ویندوز**: شیشه‌ی واقعی (Acrylic/Mica) روی ویندوز ۱۱ فعال است. روی ویندوز ۱۰ نمای شیشه‌ای داخل خود برنامه ساخته می‌شود.

## ساختار کد

```
electron/            پروسه‌ی اصلی Electron
  main.ts            چرخه‌ی برنامه، سینی سیستم، میانبرها و IPC
  windows.ts         پنجره‌ی اصلی، پنجره‌ی شناور با اندازه‌ی خودکار، لایه‌ی انتخاب صفحه
  selection.ts       خواندن متن انتخاب‌شده و چسباندن در هر برنامه
  engines/           موتورها: google، web (نشست حساب کاربری)، cli، api (OpenAI/Anthropic/Ollama)
  prompt.ts          ساخت پرامپت با سبک، واژه‌نامه و قالب بلوکی
shared/              نوع‌ها، پیش‌فرض‌ها، زبان‌ها و پروتکل Generative UI (blocks.ts)
src/                 رابط کاربری React + shadcn/ui (Base UI) + Tailwind v4
  components/result/ سطح نتیجه‌ی مولد (کارت واژه‌نامه، بلوک‌ها، اکشن‌ها)
  components/glass/  اجزای شیشه‌ای و فیلتر شکست نور
  views/             صفحه‌ها: ترجمه، تصویر، PDF، سبک‌ها، تاریخچه، تنظیمات، پنجره‌ی شناور، انتخاب صفحه
```

آیکون‌ها با `pnpm icons` از SVG ساخته می‌شوند (`scripts/make-icons.cjs`).
